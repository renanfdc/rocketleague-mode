# Texturas históricas (apenas referência) — NÃO são acessíveis

Estas são as texturas que vinham no mod antigo. Ficam aqui **só como histórico**. Nenhuma é recomendada
como recurso de acessibilidade. Para candidatas colorblind-safe, ver
[`../../../assets/texturas/`](../../../assets/texturas/).

| Arquivo | O que é | Por que NÃO usar como acessibilidade |
|---|---|---|
| `high_contrast_ball.png` | Rotulada "Alta Visibilidade" no mod | Predomina **verde + vermelho** (com magenta e amarelo). Verde-vermelho é o **pior par** para deuteranopia/protanopia (o daltonismo mais comum, ~8% dos homens) — as cores se fundem. É **anti-acessibilidade** apesar do nome. |
| `gg_lag_team.png` | Skin de "troll/lag" (era o default do mod) | Cosmético de zoeira, não pensado para visão. Byte a byte idêntica ao antigo `ball_custom.png`. |
| `joaninha_ball.png` | Foto/arte pessoal (joaninha) | Imagem decorativa, sem contraste pensado para baixa visão. |

> Lição registrada: "alto contraste" não é só cor forte — tem que **evitar o eixo vermelho-verde** e
> priorizar luminância/forma. Ver [`../../../docs/acessibilidade-visual.md`](../../../docs/acessibilidade-visual.md).
